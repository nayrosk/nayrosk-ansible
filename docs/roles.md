## bootstrap_connection

Choose how Ansible connects to the host, operator key or root password.

| Variable | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `bootstrap_connection_operator` | str | `{{ operator_user_name \| default('operator') }}` | no | Account probed with the SSH key. Follows `operator_user_name` when it is set. |
| `bootstrap_connection_probe_timeout` | int | `10` | no | Seconds before the operator probe gives up. |
| `vault_root_password` | str | secret | no | Root password used by the fallback. Required only when the operator probe fails. |

| --- | --- | --- | --- | --- |

| Variable | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |

| `hostname` | str | none | yes | Hostname added to the server certificate as a DNS name. |

## ubuntu_pro

Attach the host to Ubuntu Pro and enable Livepatch.

| Variable | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `ubuntu_pro_token` | str | secret | no | Ubuntu Pro token, read from the vault. An empty token skips attaching. |
| `ubuntu_pro_livepatch` | bool | `true` | no | Enable Livepatch once the machine is attached. |
| `first_install` | bool | `false` | no | Attach only on the first install run. |

## operator_user

Create the operator account with key-only SSH and passwordless sudo.

| Variable | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `operator_user_name` | str | `operator` | no | Name of the operator account. |
| `operator_user_uid` | int | `10000` | no | Numeric user id. |
| `operator_user_gid` | int | `10000` | no | Numeric id of the primary group, which has the same name as the user. |
| `operator_user_home` | str | `/home/operator` | no | Home directory. |
| `operator_user_shell` | str | `/bin/bash` | no | Login shell. |
| `operator_user_public_key` | str | `{{ operator_public_key }}` | no | SSH public key installed as the only authorized key. Defaults to the inventory variable `operator_public_key`, which must then be set. |

## podman_monitoring

Run node_exporter as a rootful quadlet and Caddy as a rootless quadlet in front of it.

| Variable | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `podman_monitoring_caddy_version` | str | `2.11.7` | no | Caddy image tag (`docker.io/library/caddy:<version>-alpine`). |
| `podman_monitoring_node_exporter_version` | str | `1.12.1` | no | node_exporter image tag (`quay.io/prometheus/node-exporter:v<version>`). |
| `podman_monitoring_node_exporter_listen` | str | `127.0.0.1:9100` | no | Address and port node_exporter listens on. Must stay a loopback address. Caddy proxies to `host.containers.internal`, which pasta maps to the host loopback only. |
| `podman_monitoring_caddy_basic_auth_user` | str | `admin` | no | Basic auth user protecting every Caddy route. |
| `podman_monitoring_caddy_basic_auth_hash` | str | secret | no | Bcrypt hash of the basic auth password, as printed by `caddy hash-password`. Defaults to the vault variable `vault_caddy_basic_auth_hash`, which must then be set. |
| `podman_monitoring_caddy_extra_site_addresses` | list of str | `[]` | no | Site addresses served by Caddy in addition to the hostname, the local IP and the public IP. |
| `podman_monitoring_host_loopback_ip` | str | `169.254.1.3` | no | Link-local address that the pasta instance of the Caddy container maps to the host loopback. `host.containers.internal` resolves to it inside Caddy. It must differ from podman's own `169.254.1.2`. |
| `podman_monitoring_user` | str | `{{ operator_user_name }}` | no | Rootless account running Caddy. Defaults to the operator_user role account. |
| `podman_monitoring_user_uid` | int | `{{ operator_user_uid }}` | no | Numeric id of `podman_monitoring_user`. |
| `podman_monitoring_user_home` | str | `{{ operator_user_home }}` | no | Home directory of `podman_monitoring_user`. |
| `podman_monitoring_cert_source_directory` | path | `{{ local_ca_directory }}` | no | Directory holding `server.crt` and `server.key`. Defaults to the local_ca role directory. |
| `hostname` | str | none | yes | Hostname served by Caddy, also the first name of the server certificate. |

## fail2ban

Ban repeated SSH and Caddy authentication failures through UFW.

| Variable | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `fail2ban_bantime` | str | `1h` | no | Ban duration. |
| `fail2ban_findtime` | str | `10m` | no | Window in which `fail2ban_maxretry` failures trigger a ban. |
| `fail2ban_maxretry` | int | `3` | no | Failures allowed inside the find window before a ban. |
| `fail2ban_ignoreip_extra` | list of str | `[]` | no | Extra addresses or networks never banned, added to the detected ones. |
| `fail2ban_caddy_log` | str | `/home/{{ operator_user_name }}/.caddy/logs/access.log` | no | Caddy JSON access log watched by the `caddy-auth` jail. |
